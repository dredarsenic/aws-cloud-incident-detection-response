# Screenshots

Portfolio screenshots can be stored in this directory.

Recommended evidence:

1. Terraform successful deployment summary.
2. Lambda synthetic StopLogging incident response.
3. DynamoDB incident record.
4. S3 preserved evidence objects.
5. CRITICAL StopLogging SNS alert.
6. HIGH UpdateTrail SNS alert.
7. EventBridge rule configuration.

Before committing screenshots, redact personal email addresses, AWS account identifiers where appropriate, source IP addresses, tokens, credentials, and other unnecessary identifying information.
